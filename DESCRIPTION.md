# Short description (AppSource — 100 chars)

GitHub-style calendar heatmap for any date measure. Three layouts, 7 colour schemes, accessible.

# Long description (AppSource)

PulseGrid renders any date-keyed measure as a calendar heatmap, the way GitHub shows contributions. It is the calendar-density visual Power BI has been missing — built for analysts who want a seasonality pattern, on-call rotation density, sales heatmaps, anomaly calendars, or quality-of-data coverage.

**Three layouts**
- *Year strip* — classic GitHub layout (weeks across, days down). Best for spotting weekly cadence and seasonality across one or more years.
- *Month grid* — twelve mini-calendars side by side, one per month. Best for executive reports and calendar look-ups.
- *Week strip* — narrow 7-column grid for compact tiles in dashboards.

**Seven colour schemes**
- GitHub Green · Ocean Blue · Sunset · Plasma · Viridis (colour-blind safe) · Diverging (red → white → blue, ideal for variance) · Custom (any low/mid/high).

**Accessible by design**
- Every cell is keyboard-focusable with an ARIA label that reads the date and value.
- Optional cell borders for low-contrast environments.
- Forced-colours CSS fallback for Windows high-contrast mode.
- Tooltips fire on focus as well as hover.

**Privacy and sandbox compliance**
- No outbound HTTP calls.
- No third-party JS at runtime.
- `privileges` array empty.
